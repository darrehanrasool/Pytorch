PyTorch is a leading, open-source machine learning and deep learning framework primarily
developed by Meta's AI Research lab (FAIR) and currently managed under the Linux Foundation.
Known for its Pythonic nature, flexibility, and speed, it has become the standard tool for 
cutting-edge AI research and industrial applications, powering systems like OpenAI's ChatGPT 
and Tesla Autopilot.

Key Pillars of PyTorch

Tensor Computation:
PyTorch operates on Tensors, which are multi-dimensional arrays similar to NumPy arrays but 
with the crucial ability to be accelerated on GPUs using NVIDIA's CUDA backend.

Dynamic Computation Graph (Autograd):
Unlike frameworks that use static graphs PyTorch uses a define-by-run approach. It dynamically 
builds a directed acyclic graph during execution, allowing you to change network behavior on 
the fly and debug easily using standard Python debuggers.

Deep Ecosystem:
 It features powerful built-in libraries like torch.nn for building neural network layers, torch.optim
for optimization algorithms, and specialized domain libraries like TorchVision and TorchAudio
